rederive / demos

Small demos of the binding layer: geometry as a derivation of the record. Each demo is one self-contained HTML file in the Kestrel weight class — no build step, no external assets, works from file:// or any static host. A sprite stack is the cheapest rendered derivation of a record, so two of the three demos render with it.

turntable — identity → form
Five records rendered as sprite stacks derived from their own identity bytes: type picks the silhouette, identity seeds the variation, lifecycle state restyles the same record's form. Drag to spin.
ONE FILE · DERIVATION IN-PAGE · SPRITE STACKS PER RUSTGIS-SPRITE (SOM-DOC-10898)
the wall — record → derivation, with the check
One wall record with a door opening. The solid is re-derived from the record's parameters and measured; the analytic volume from the same parameters is the check. Move a parameter, the derivation follows.
ONE FILE · REFERENCE DERIVATION — KERNEL NUMBERS LAND WITH THE PIPE PROOF
the pipe — one record, two connectors
The same wall enters as a real Revit encoder record and leaves as an Onshape part under the connector's identity mapping. The foreign keys change; the IMBUUID between them does not.
ONE FILE · REVIT SIDE REAL (SOM-DOC-10884) · ONSHAPE INSTANCE ILLUSTRATIVE (SOM-DOC-10886)
